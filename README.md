# Java Spring Expert - DevSuperior

Este repositório reúne todos os projetos e exercícios desenvolvidos ao longo do curso *Java Spring Expert*, oferecido pela [DevSuperior](https://devsuperior.com.br/).  
Cada branch representa uma etapa prática do curso, contendo implementações, desafios e anotações de aprendizado.

A proposta é manter um histórico versionado da evolução técnica durante a formação.

## Estrutura do Repositório

1. Setup do projeto DSCatalog, camadas, mapeamento JPA e operações completas de CRUD.
2. Fundamentos de testes, TDD, JUnit, testes de repository e testes de unidade com Mockito.
3. Bean Validation, tratamento de erros de validação, OAuth2, JWT e pré-autorização por perfil.
4. Consulta e busca paginada de produtos, CORS, cadastro de usuário e recuperação de senha.
5. Setup, seleção de pacotes, fluxos de cobertura e relatórios de testes.
6. Setup, DSL do RestAssured e testes de integração da API.

> Cada pasta possui seu próprio README explicando o contexto, e desafios resolvidos.

## Tecnologias e Ferramentas Utilizadas

- Java 21+
- Spring Boot
- Spring Data JPA / Hibernate
- Spring Web / REST
- Spring Security
- JUnit / Mockito
- RestAssured
- Jacoco
- Maven
- Postman
- Git / GitHub
- IntelliJ
